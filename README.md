# 🦔 Sonic Adventure (2003) – Tunisian Voice Edition 🇹🇳 BY --help !

A custom fan project bringing the classic **Sonic Adventure (2003)** experience to life with authentic **Tunisian dialect (Derja)** voice acting!

> ⚠️ **Project Status:** Work in Progress (WIP). Only **Mission 1** is currently completed and playable.

---

## 📌 Project Overview
This project aims to re-imagine Sonic Adventure with local voice acting, blending classic nostaglic gameplay with Tunisian humor and dialogue. 

* **Current Stage:** Early Alpha / Playable Demo
* **Available Content:** Mission 1 (Full voiceover & integration)
* **Language:** Tunisian Arabic (اللهجة التونسية)

---

## 🎮 Features
- **Custom Tunisian Voice Acting:** Dialogue re-recorded in Derja for Mission 1.
- **Original Nostalgia:** Preserves the core mechanics and aesthetic of the 2003 release.
- **Playable First Mission:** Complete the first stage from start to finish with new audio.
